Two Blender add-ons, open source

2026
Own toolingPipeline

Both exist because I kept hitting the same problems myself, and neither is a toy — they are tested, documented, and running in my own work.

  • Rig Doctor — twenty pre-export checks across scene, transforms, geometry, UV, rig and skinning. Each finding says what it will do downstream, not just what it is. One-click fixes only where the fix is unambiguous; n-gons and missing UVs stay a report line rather than a guess. 33 assertions against a deliberately broken rig.
  • Engine Export — Blender's FBX dialog has forty options; eight decide whether the character lands correctly. Unity and Unreal want opposite values for three of them. Sets them per engine. 46 assertions, including the preset values themselves.
  • Both run headless, so they gate an export step in a build script instead of relying on someone remembering
  • Tested on Blender 3.4.1 and 5.0. GPL-3.0, as Blender add-ons must be
